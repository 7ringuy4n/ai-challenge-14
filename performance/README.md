# JMeter performance profiles

Apache JMeter 5.6.3 is provisioned under `$HOME/.local/jmeter` for this host. Reprovision it without root privileges with `scripts/performance/install-jmeter.sh`; the script downloads the pinned Apache distribution, verifies the fixed SHA-512, and refuses to replace another version. The SHA-512 is from the official [Apache JMeter binary distribution directory](https://downloads.apache.org/jmeter/binaries/); the archive is `apache-jmeter-5.6.3.tgz`. The download/checksum/extraction path was exercised in `/tmp/jmeter-provision-check`, and the installed binary reported 5.6.3. JMeter execution requires Java; the current runner uses the configured Java 21 runtime. The seven executable JMX profiles are baseline, normal, peak, stress, spike, soak, and concurrent-claims. Profiles are XML checked in and can be run with `scripts/performance/run-profile.sh PROFILE`; the runner records Java/JMeter versions, profile SHA-256, git commit/worktree state, exact source hash when available, effective load parameters, approved thresholds, JTL/JMeter log archives, HTML report archive, and 5-second host/database/outbox samples. Credentials are materialized in an owner-only temporary file, never in a JMeter command argument, and removed on exit.

Run the documented local stack first (`bash scripts/setup.sh`). The benchmark targets approved 2026-10-17 by the user are P95 ≤500 ms, P99 ≤1,000 ms, and error rate ≤1%. Use `python3 scripts/performance/compare-runs.py reports/performance` to regenerate the aggregate report. Existing selected runs are retained as JTL/JMeter gzip files and HTML report tarballs with JSON summaries and system-metrics JSONL. Earlier failed attempts are retained in `reports/performance/` as historical evidence and excluded if they lack a summary.

The selected complete runs were executed on 2026-10-17 against the business, outbox, and OpenTelemetry implementation before a final request-log context-field adjustment. These runs came from a dirty worktree: their recorded Git commit is the base commit only and the exact working-tree source hash was not captured. Each JMX profile SHA-256 is retained. The post-adjustment 5-second baseline validates runner metadata/provenance and compression; it is not a full performance run. No result is presented as a benchmark of byte-identical final source. Results and this limit are in `reports/performance/comparison.json` and `reports/verification/REQ-015-final.json`.
