## Final-source JMeter execution

The seven approved profiles ran sequentially on 2026-10-17 against `http://127.0.0.1:8080`, using Apache JMeter 5.6.3 and OpenJDK 21.0.12.1. The application and PostgreSQL 16 ran in the documented Compose stack. Each run manifest records the clean source commit/hash and the profile's `.jmx` hash. The captured SHA-256 before/after lists for every JMX and properties file are identical. Full compressed JTLs, JMeter logs, HTML dashboards, per-run summaries, run manifests, container/database/outbox metrics and the aggregate comparison are under [`REQ-017-jmeter-final`](../verification/REQ-017-jmeter-final).

The seven final-source profiles produced 1,089,197 samples. Six passed: baseline, normal, peak, spike, soak and concurrent-claims. Stress at 500 virtual users produced 88,762 samples at 1,460.5 requests/sec, with P95 564 ms, P99 767 ms and zero errors. It fails the P95 requirement. A later default-config repeat also failed (P95 917 ms, P99 1,077 ms, zero errors). These measurements vary substantially on the shared local eight-CPU host, where JMeter, the app, PostgreSQL and desktop/container workloads compete for resources.

Temporary diagnostic runs tried Hikari pool 40 and Tomcat max threads 500. Both materially reduced throughput and exceeded both percentile limits; an independent review advises against adopting either setting. The diagnostic executions were sequential, used evolving database contents, and did not use a reset snapshot or randomized order. They are not causal proof. No threshold was changed, no source tuning was adopted, and no JMeter evidence is represented as passing when it failed. A dedicated performance environment and controlled same-data test are needed to establish a safe remediation.

The latest local inventory/export covers 65 accessible project-related sessions and 8,483 message/tool records. All 65 transcript hashes and contained unique paths verify. This mandatory audit condition has not been waived.

Both the failed performance gate and blocked historical payload gate prohibit acceptance and prohibit merging `develop` into `main`. No push has been performed. The project remains **NOT ACCEPTED**.
